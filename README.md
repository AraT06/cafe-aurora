# Café Aurora

Proyecto de cafetería con backend en Express/PostgreSQL y frontend en Angular.

- [`trabajo-ia/`](./trabajo-ia) — backend (API REST, autenticación JWT, carrito, favoritos, pedidos, chatbot con Claude API).
- [`frontend/`](./frontend) — frontend Angular que consume la API.

Instrucciones de configuración y ejecución en el README de cada carpeta.
